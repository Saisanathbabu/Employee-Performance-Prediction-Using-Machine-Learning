# Employee Productivity Prediction Using ML

 📌 Overview
This project is a Flask-based web application that predicts employee productivity using Machine Learning models  

-->It analyzes multiple factors such as department, team, targeted productivity, overtime, incentives, idle time, style changes, and workforce details to provide **real-time insights** into performance trends.



🚀 Features
- Interactive web interface with a clean, responsive design
- Input form for employee details
- Real-time productivity prediction using trained ML models
- Dataset visualization and insights
- Professional UI with background images and styled components



 🛠️ Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** Flask (Python)
- **Machine Learning:** Scikit-learn, XGBoost
- **Deployment:** Localhost (extendable to cloud platforms)
