About This Project

This web application leverages Machine Learning to predict employee productivity based on multiple factors such as department, team, targeted productivity, overtime, incentives, idle time, and more.

Dataset

The dataset includes employee performance metrics collected across different quarters, departments, and teams. It provides insights into productivity trends and workforce efficiency.

Machine Learning Approach

We trained models using Linear Regression,Random forest and XGBoost to analyze productivity patterns. The final model is saved as gwp.pkl and integrated into this Flask application for real-time predictions which is this application

Purpose

The goal of this project is to help organizations identify productivity drivers, optimize workforce management, and enhance overall efficiency using data-driven insights.
